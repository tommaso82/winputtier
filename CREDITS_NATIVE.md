# Source and theme credits

WinPuttier is a native Windows C++ port inspired by [Puttier](https://github.com/anonimoanemico/puttier), originally released under CC0 1.0. The original project and its LICENSE are retained.

The program fetches metadata and theme files on demand, without bundling third-party theme collections:

- https://github.com/mbadolato/iTerm2-Color-Schemes
- https://github.com/jacek0x/pretty-putty (previously jacektrocinski/pretty-putty)
- https://github.com/teeli/dracula-putty
- https://github.com/AlexAkulov/putty-color-themes

Theme authors, contributors, trademarks and respective licenses remain those of the upstream projects. Users should check each source's licensing terms before redistributing downloaded themes. In particular, the AlexAkulov repository does not list a clear redistribution license; its themes are not included in the WinPuttier distribution.
