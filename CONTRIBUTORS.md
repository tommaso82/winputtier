# Contributors and acknowledgments

WinPuttier combines a new native Windows implementation with the work of the original Puttier project and independent terminal-theme creators.

## WinPuttier

- **[Tommaso (@tommaso82)](https://github.com/tommaso82)** — creator, technical lead and maintainer; requirements, design direction and testing.
- **[ChatGPT (GPT-6)](https://chatgpt.com/)** — AI-assisted C++/Win32 implementation, debugging, interface development and documentation.

## Original Puttier

- **[anonimoanemico](https://github.com/anonimoanemico)** — author of [Puttier](https://github.com/anonimoanemico/puttier), the original Python project. The [original source](puttier/), [README](docs/README-puttier-original.md) and [CC0-1.0 license](LICENSE) are preserved.

The original Puttier README thanks these theme-source contributors:

- **[mbadolato](https://github.com/mbadolato)** — [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes)
- **[jacektrocinski](https://github.com/jacektrocinski)** — [pretty-putty](https://github.com/jacektrocinski/pretty-putty)
- **[teeli](https://github.com/teeli)** — [dracula-putty](https://github.com/teeli/dracula-putty)

WinPuttier also supports [AlexAkulov/putty-color-themes](https://github.com/AlexAkulov/putty-color-themes) as an additional theme source.
