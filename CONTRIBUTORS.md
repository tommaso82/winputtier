## Original software

- **[anonimoanemico](https://github.com/anonimoanemico)** — creator of **[Puttier](https://github.com/anonimoanemico/puttier)**, the original Python application that inspired this native Windows port. Its [README](docs/README-puttier-original.md), [source code](puttier/) and [CC0 1.0 license](LICENSE) remain in this repository.
- **The original Puttier's upstream contributors and sources** are acknowledged below and in the historical README. WinPuttier is a separate adaptation and does not claim authorship of their work.

## Theme collections credited by the original Puttier

The original Puttier README explicitly thanked the following people and their projects:

- **[mbadolato](https://github.com/mbadolato)** — [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes), including its PuTTY-compatible theme collection.
- **[jacektrocinski](https://github.com/jacektrocinski)** — [pretty-putty](https://github.com/jacektrocinski/pretty-putty) (the theme source originally referenced by Puttier; see also the configured source [jacek0x/pretty-putty](https://github.com/jacek0x/pretty-putty)).
- **[teeli](https://github.com/teeli)** — [dracula-putty](https://github.com/teeli/dracula-putty).

These are **the original project's three credited theme sources**, preserved here by name rather than replaced with an anonymous list of links.

## Individual theme designers and contributors — full original credits

**[CREDITS.md](CREDITS.md) is preserved intact from the original repository.** It includes an extensive, individually attributed catalogue of terminal color scheme authors and contributors (more than 200 source links), along with the relevant upstream references and inspirations. Those individuals deserve credit for **their own themes**, not only the project that collected them.

Please see **[the complete original list of theme credits →](CREDITS.md)**; it is part of the WinPuttier repository and has not been condensed, overwritten or reattributed.

The theme repositories are maintained independently. Themes downloaded at runtime retain their upstream authorship and respective licensing conditions; WinPuttier does not claim copyright over them.

## GitHub's automatic Contributors list

GitHub generates the **Contributors** panel from Git commit authors and associated GitHub accounts. A repository document cannot register an AI assistant as a GitHub user, and we do not invent an account or identity for ChatGPT. This document and the README provide accurate public attribution without misrepresenting GitHub authorship.

Thank you to the original authors and everyone who makes free and open-source software possible.
