# WinPuttier 0.5.2

Native Windows PuTTY colour-theme manager for **Windows 10/11 x64**.

## What's fixed

- Removed the unwanted black/red dotted focus rectangle inside the **IT | EN** language selector.
- Kept the compact rounded selector, its blue active-language highlight and one-click switching unchanged.
- No changes to PuTTY session colours, theme handling or language preferences.

All features from 0.5.1 remain available: built-in English/Italian translations, offline themes, ANSI colour preview, palette editing, theme backups and restore.

## Download

Download **WinPuttier.exe** from the release assets. This is a portable **unsigned** executable; no installer, .NET or Python required.

**SHA256SUMS.txt** contains the SHA-256 checksum for verifying the download.

Credits for the original Puttier project and theme authors are preserved in [CREDITS.md](https://github.com/tommaso82/winputtier/blob/main/CREDITS.md).
